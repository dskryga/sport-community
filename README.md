# Sport Platform

Платформа для поиска и организации спортивных мероприятий с людьми поблизости.

## О проекте

Pet-проект для демонстрации навыков разработки на Java и Spring Boot. Платформа позволяет пользователям создавать спортивные события, присоединяться к существующим и находить мероприятия в радиусе заданной геолокации.

### Основной функционал (MVP)

- Создание спортивных событий с указанием даты, времени, места на карте
- Поиск событий поблизости с использованием PostGIS пространственных запросов
- Присоединение к событиям с ограничением количества участников
- Управление профилем пользователя
- Просмотр списка участников события

## Технологический стек

### Бэкенд
- Java 17
- Spring Boot 3
- Spring Data JPA + Hibernate Spatial
- Spring Security + JWT
- PostgreSQL 16 + PostGIS 3.4
- Liquibase (управление миграциями)
- Maven
- Testcontainers (интеграционные тесты)

### Инфраструктура
- Docker / Docker Compose
- GitHub Actions (CI)

### Планируемые улучшения
- Redis для кеширования геопоиска
- WebSocket уведомления
- Telegram бот
- Swagger/OpenAPI документация
