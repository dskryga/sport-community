# Sport Platform

Платформа для поиска и организации спортивных мероприятий с людьми поблизости.

## О проекте

Pet-проект для демонстрации навыков разработки на Java и Spring Boot. Платформа позволяет пользователям создавать спортивные события, присоединяться к существующим и находить мероприятия в радиусе заданной геолокации. Часть функциональности постепенно выносится в отдельные сервисы, взаимодействующие через Kafka — первый пример: `notification-service` для email-уведомлений.

### Основной функционал (MVP)

- Регистрация и аутентификация (JWT), роли `USER` / `ADMIN`
- Создание спортивных событий с указанием даты, времени, места на карте
- Поиск событий поблизости с использованием PostGIS пространственных запросов
- Присоединение к событию и отмена участия
- Комментарии к событиям
- Управление профилем пользователя
- Просмотр списка участников события
- Категории событий (создание — только для администраторов)
- Email-уведомления о регистрации и записи/отмене участия в событии (асинхронно, через Kafka)

## Архитектура

Проект — multi-module Maven reactor. Основная бизнес-логика пока в монолите (`community-app`), а взаимодействие с новыми сервисами идёт через Kafka:

- **community-app** — основной бэкенд: REST API, JPA/PostGIS, JWT-аутентификация, кеш на Redis
- **community-contracts** — общие DTO Kafka-событий, используемые всеми сервисами
- **notification-service** — слушает Kafka и отправляет email-уведомления

## Технологический стек

### Бэкенд
- Java 17
- Spring Boot 3, Spring Data JPA + Hibernate Spatial
- Spring Security + JWT
- PostgreSQL 16 + PostGIS 3.4
- Liquibase (управление миграциями)
- Redis (кеширование)
- Apache Kafka (KRaft) + Spring Kafka — асинхронное взаимодействие между сервисами
- Maven (multi-module reactor)

### Инфраструктура и observability
- Docker / Docker Compose
- Kafka UI — просмотр топиков и сообщений
- Mailpit — приём писем в dev-окружении (вместо реальной отправки)
- Prometheus + Grafana — метрики приложения, PostgreSQL и Redis
